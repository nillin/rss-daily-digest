我们一直在等待的 AI 颠覆已经到来

来源：simonwillison.net · 原作者：Paul Ford (NYT) · 2026-02-18 · 原文链接

Paul Ford 在《纽约时报》发表的新观点文章。不出所料，作为 Paul 的文章，其中充满了值得引用的片段，但有几段特别引起了我的注意。

Paul 描述了许多其他程序员都观察到的11月时刻，并强调了 Claude Code 复活旧副项目的能力：

[Claude Code] 一直是一个有用的编码助手（coding assistant），但在11月它突然变得好得多，从那以后我一直在完成那些在文件夹里放了十年或更久的副项目。看到旧想法变成现实很有趣，所以我保持着稳定的进度。也许每天占用我半小时的时间，以及 Claude 一小时的时间。

对我和许多科技界的其他人来说，11月是一个巨大的惊喜。之前，AI 编码工具通常很有用，但断断续续且笨拙。现在，这个机器人可以连续运行整整一个小时，制作出完整的、经过设计的网站和应用程序，虽然可能有缺陷，但是可信的。我花了整整一次治疗时间来谈论这件事。

作为一家受人尊敬的咨询公司（Postlight）的前 CEO，他处于评估潜在影响的有利位置：

当你看到一个大型语言模型（LLM）轻松解决一些可怕的、昂贵的问题时——比如将数据从旧平台迁移到现代平台——你会感觉到大地在移动。我曾是一家软件服务公司的首席执行官，这使我成为一名专业的软件成本估算师。几周前当我重启我混乱的个人网站时，我意识到：我会付25,000美元让别人来做这件事。当一个朋友让我转换一个庞大、棘手的数据集时，我下载了它，清理了它，并使它变得漂亮且易于探索。在过去，我会收费350,000美元。

最后那个价格是2021年的全额零售价——它意味着一个产品经理、一个设计师、两个工程师（一个高级工程师）以及四到六个月的设计、编码和测试。还有维护费用。定制软件贵得惊人。然而今天，当星星对齐、我的提示（prompts）奏效时，我可以在周末和晚上为了乐趣完成价值数十万美元的工作，只需要 Claude 每月200美元的订阅计划。

他还巧妙地捕捉到了探索这项技术所涉及的固有社区张力：

我爱的所有人都讨厌这东西，而我讨厌的所有人都喜欢它。然而，可能是因为最初吸引我进入科技领域的那些性格缺陷，我还是烦人地兴奋着。

在 Raspberry Pi 上使用 Hailo 进行 Frigate 物体检测

来源：jeffgeerling.com · 2026-02-18 · 原文链接

我运行 Frigate（一个开源的网络视频录像机）来录制安全摄像头画面，并检测视野中的人、汽车和动物。我的当前 Frigate 服务器运行在 Raspberry Pi CM4 上，通过 USB 插入了一个 Coral TPU（张量处理单元）。

Raspberry Pi 为 Pi 5 提供了多款 AI HAT+（硬件附加板），内置 Hailo-8 或 Hailo-8L AI 协处理器，它们对于 Pi 上的低功耗推理（如图像物体检测）非常有用。

Frigate 提供了 Hailo 支持，但在我的新构建上让它工作让我费了一番周折，所以我在这里记录我的构建过程。

假设你在 Pi 5 或 CM5 上有一个全新的 Pi OS 安装，并且你通过 PCIe 连接了 Hailo 模块，请执行以下操作：

  • 按照 Frigate 的指南从源代码安装 Hailo-8 驱动程序。
  • 按照 Frigate 的指南在你的 Frigate config.yml 中将 Hailo 设置为物体检测器。
  • 启动 Frigate。

如果你看到这样的消息：

WARNING : CPU detectors are not recommended and should only be used for testing or for trial purposes.

那么你的检测器配置可能是错误的。回头检查你在 frigate.yml 中的模型和检测器配置。

PCIe force_desc_page_size 问题

除了配置问题外，我遇到了这个错误：

[HailoRT] [error] CHECK failed - max_desc_page_size given 16384 is bigger than hw max desc page size 4096
RuntimeError: HailoRT inference thread has stopped, restart required.

修复方法：创建文件 /etc/modprobe.d/hailo_pci.conf，内容如下：

options hailo_pci force_desc_page_size=4096

然后重启 Pi，或运行：

sudo modprobe -r hailo_pci
sudo modprobe hailo_pci

修复后，Hailo 以大约 12ms 的推理速度运行，整体 CPU 使用率非常低。好处是这在更便宜的 Hailo-8L 上也能工作，你可以在 70 美元的 AI HAT+ 中找到它，通常比现在已经过时的 Google Coral TPU 便宜得多。

我仍然不明白为什么 Google 在一代之后就放弃了 Coral。看起来他们本可以主导"边缘 TPU"市场，但在达到 4 TOPS（每秒万亿次操作）后就放弃了。
