1. 尝试为我的博客和新闻通讯引入赞助

来源: simonwillison.net | 原文链接

2026年2月19日

我一直对接受博客赞助的想法持抵触态度。我珍视自己作为独立声音的可信度，不想冒险损害这一声誉。

后来我了解到 Troy Hunt 的赞助方式，他最早在 2016年写过这个话题。Troy 采用的是在页面横幅中放置简单的文本行——没有 JavaScript，没有 cookies（浏览器存储的小型数据文件），不显眼但能为赞助商提供价值。我可以接受这种方式！

以这种方式接受赞助帮助我保持独立性，同时抵消了不从事全职工作的机会成本。

首先，我按周销售赞助位。赞助商可以在我的博客上获得那个不显眼的横幅，同时在我的 newsletter（电子邮件通讯）顶部展示他们的赞助信息。

我不会为了赞助而撰写内容。我希望与我合作的赞助商理解，我作为独立声音的可信度是我拥有受众的关键原因，损害这种信任对所有人都不利。

Freeman & Forrest 帮助我设置并销售了第一批赞助位。同时感谢 Theo Browne 帮助我思考我的方法。

30. 你只是以为他们为你工作

来源: steveblank.com | 原文链接

当我还是一名新晋市场副总裁时，我得到了一个痛苦的教训：我的 PR（Public Relations，公共关系）代理公司到底为谁工作。后来我意识到，这对我所有的外部供应商都是如此。而更晚些时候，我才明白我真正应该要求他们做什么。

这些教训至今仍然适用，尽管 AI Agents（AI 代理）将颠覆这一切，PR 最终会成为许多不再以当前形式存在的行业之一。

原因如下。

我们是一家刚上市的新公司，即将推出第一款产品。我向一家主流出版物（名字已经在时间的迷雾中消失了，要么是华尔街日报，要么是纽约时报）提供了独家报道，我以为这是有 embargo（禁令）的。（Embargo 是一个花哨的术语，指出版物同意在特定日期和时间之前不发布报道。）令我惊讶的是，这家报纸在我们约定的日期前几天就发布了，搞砸了原本应该是完美同步的新闻发布活动。

我对我的 PR 代理公司非常愤怒，天真地告诉他们去告诉那家出版物，我们公司再也不会与他们合作了。虽然我不记得确切的对话内容，但今天我可以想象我们 PR 代理公司的 CEO 在电话另一端带着笑意的表情。

我花了多年时间才完全理解我的服务提供商和顾问实际上为谁工作，以及他们真正关心的长期关系——提示：不是我。

背景

我以为与 PR 代理公司合作非常简单。作为市场副总裁，我的角色首先是制定一个传播策略，回答"我们在做什么以及为什么"。

例如，我们的营销目标是：

  • 为我们的产品创造需求并将其引入我们的销售渠道
  • 为潜在客户创造对我们公司和品牌的认知
  • 为筹款（VC 风险投资、天使投资人、企业合作伙伴）创造认知
  • 为我们公司的潜在收购方创造认知

接下来，我会弄清楚如何应用这个策略。"如何"只需要四个步骤：

  • 了解我的受众
  • 为特定受众制定信息
  • 选择信息将被阅读/看到/听到的媒体
  • 选择你希望传递信息的信使

最后，我写下了我对受众、信息、媒体和信使应该是什么的假设。然后我用这个来寻找和雇用 PR 代理公司。我的选择基于两个问题的答案：

1) 他们对我第一次尝试的受众、信息、媒体和信使有什么看法。希望他们能比我第一次尝试做得更好。

2) 他们能否在战术上执行——意思是他们是否拥有或能够获得与正确的媒体和信使的关系，以便在我的客户会看到的媒体上获得新闻提及和报道。

他们为我工作

我认为我的 PR 代理公司和我的公司之间的商业模式是一个简单的单边市场——我是 PR 代理公司的客户，PR 代理公司为我工作。

与媒体交谈是我付钱让他们为我做的事情。他们在宇宙中的位置围绕着我旋转。非常直接了当。

现实并非如此简单。

是的，我是 PR 代理公司的客户，但他们的长期关系以及他们业务的核心是媒体机构中的人——他们最有价值的资产。我实际上是多边市场的一部分。

既然如此，无论我作为客户提出什么要求，他们都不可能对一个重要的新闻机构大喊大叫。

而且我只是众多客户之一

不仅如此，我只是我的 PR 代理公司服务的众多客户之一。正如我后来了解到的，我是他们较小的客户之一。该代理公司为多家公司服务，虽然他们很乐意收我的钱并且（大多数情况下）喜欢与我们合作，但如果他们认为我太不讲理或要求他们实现不可能的事情，他们可以用另一个客户替换我的关系。所以世界实际上是这样的。

实际上，我在他们宇宙中的位置非常小。

这对几乎所有向公司和个人提供服务的外部供应商和顾问都是如此。想想游说者——他们不会与政府官员产生矛盾——那些是他们的长期关系。或者建筑师和建筑承包商，他们与分包商、规划委员会等有着重要的长期关系。

最后一件事——学习他们所知道的

直到我职业生涯的后期，我才学到了关于服务提供商和顾问的最宝贵的一课。

我曾聘请一位顾问为我们公司在日本建立分销和制造。我对这些领域一无所知，并联系到了一位世界级的顾问。我和他们一起去了日本一次，但他们完成了所有的关系建立，并且像当地人一样熟悉那里。在我们的案例中，这种关系成功了——至少表面上是这样。但事后看来，我意识到我犯了一个巨大的战略错误。我对日本的分销和制造如何运作学到的东西很少。

我得到了我付费的"服务"，但没有意识到我失去的机会。我应该做的是利用他们来教我日本分销是如何运作的，而不仅仅是为我做这件事。这是我发现许多创始人陷入的陷阱。如果你当时问我，我的借口会是，"我没有足够的时间或带宽，甚至没有兴趣。"但缺点是，这不仅让你永远依赖服务提供商/顾问，而且你和你的公司永远无法比那个单一联系点更聪明。想想苹果对富士康和中国公司的依赖。

虽然我在雇用某人建立分销和制造，但我也应该雇用他们来教我什么有效、什么无效以及为什么。这会让我更聪明，并帮助我制定更好的策略来使用他们——并最终取代他们。

在我的 PR 代理公司的案例中，这是我不理解的：最成功的客户-PR 代理公司关系不是交易性的。它们是以给予和接受为标志的伙伴关系——围绕信息传递、传播策略和战术等。

如果我早点意识到这一点，我本可以要求我的 PR 代表解释 PR 是如何运作的，以及什么才是一个好故事。从他们的角度理解事情会让我成为一个更好的客户——以及我们想要帮助讲述我们故事的记者的更好来源。相反，我花了几十年才学会。

一些服务提供商不会分享他们的知识，声称这是他们的专有秘方。更多的人想一次又一次地向你出售他们的服务。但如果你愿意为他们的时间付费，其他人愿意这样做。找到他们并雇用他们，让自己成为一个更明智的管理者。

未来将是 AI Agents

这就是为什么这与你现在相关，无论你是刚毕业还是超过 40 岁（甚至 30 岁！）。比我们想象的更快，这些服务中的大多数将由 AI agents 完成。有几个已经做得很好，而且改进的速度令人震惊。

对于我们的 PR 代理公司示例，虽然信息、媒体、信使、受众循环将保持不变，但它将完全由 AI Agents 运行。

今天，PR 代理公司已经使用 AI 来起草新闻稿、博客文章和社交媒体更新的初始版本（感谢 ChatGPT）。现在有 AI 工具可以根据记者的报道历史和兴趣定制内容并向他们推销。同样的 AI agents 生成个性化的电子邮件主题行和正文。与此同时，为了主动管理和保护公司的品牌，PR AI agents 可以监控和扫描数百万个来源，以跟踪品牌提及、情绪和竞争对手活动，以及检测新兴的负面叙述，并预测潜在的声誉威胁——在它们到达主流之前几周。

与此同时，博主和记者将使用他们自己的 AI 工具来扫描和过滤这些推销。问题是他们是否会放弃与 PR 专业人士的个人联系，还是欢迎让他们的工作更容易地筛选噪音？

欢迎来到媒体传播的机器对机器时代。

PR 转型或消失

今天，这些 AI 工具是独立的、定制的应用程序。不久之后，它们将成为完整的工作流程，AI agents 自主执行大部分任务，人类进行监督。然而，这些工具不可避免地将转变为内部营销部门甚至小企业自己启动的另一种类型的 vibe coded 应用程序。在采用这些工具方面落后的公司将处于竞争劣势。今天存在的 PR 代理公司可能会消失和/或转变为提供更高级别的服务。

这只是 AI 对一个依赖高接触人类的业务的影响。更多的将随之而来。

这些 agents 将如何完成我们派遣它们执行的任务的大部分方式将是黑盒子。我们会得到很好的结果，但不知道它们是如何发生的。目前它们都没有"解释你为什么这样做以及如何做"的模式。

我想知道这是会让我们更聪明，还是只会创造更多的 AI 垃圾。

那些找到如何使用这些工具的方法，让他们能够更深入地投入到工作中关键的人类方面的服务提供商，将是你想要合作的人。为了让你的公司获得优势，找到他们，雇用他们，并学习他们所知道的——包括如何有效地使用 AI。
